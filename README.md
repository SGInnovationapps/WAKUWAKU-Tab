# わくわくタブレット

2〜3歳向けの iPad 用知育アプリ（PWA）。GitHub Pages で公開し、Safari の「ホーム画面に追加」でオフライン動作します。

## コンテンツ

| コンテンツ | ステージ |
|---|---|
| ① なぞり書き（9） | よこの せん / たての せん / くねくね / やま / まる / なみなみ / さんかく / しかく / うずまき |
| ② 神経衰弱（12） | 4枚：どうぶつ・くだもの・いろ ／ 6枚：かたち・のりもの・いろ ／ 8枚：やさい・どうぶつ・うみ ／ 10枚：いろ・くだもの・まぜこぜ |
| ③ 数字ならべ（11） | 1と2 / 1〜3 / てんてん→すうじ / すうじ→てんてん / 1〜4 … 1〜10 |
| ④ パズル（15） | 形：りんご(2) / おうち(3) / ゆきだるま(3) / くるま(4) / うさぎ(4) ／ ジグソー：いちご・ぶた・バス(4) / くだもの・やさい・のりもの(6) / どうぶつ・くだもの・やさい・のりもの(8) |

ステージは画面上部のボタンで切り替え。クリアすると大きな「〇」と紙吹雪のあとに「やったね！」が出て、「つぎへ」で次のステージに進みます。できなかったときはその場所に「×」が出ます（画面はゆらしません）。神経衰弱でペアがそろったときは、そのカードに小さな「〇」が出ます。クリア済みは緑、遊んでいるステージは黄色で表示されます。

## 遊び時間の上限

ゲーム画面を開いている時間が合計10分になると「かんせい！」が表示・読み上げされ、ゲームを続けられなくなります。保護者が画面の「2秒間長押しで解除」を押し続けると解除され、メニューに戻ります。

- メニュー表示中・iPad がスリープ中は数えません
- アプリを閉じても経過時間と終了状態は残ります（最後に遊んでから60分たつと経過時間はリセット）
- 時間を変えるときは `js/app.js` の `10 * 60 * 1000` を書き換えます
- 動作確認用に `index.html?limit=30` で開くと、30秒で終了します

## 構成

```
index.html        画面の器（メニュー・確認・ほめる演出・設定）
manifest.json     PWA 設定
sw.js             オフラインキャッシュ
css/style.css     全スタイル
js/app.js         画面切替・ホーム長押し・効果音・読み上げ・ステージ管理
js/tracing.js     ① なぞりがき（VARIANTS にパスを追加すればステージが増える）
js/memory.js      ② しんけいすいじゃく（ITEMS に絵柄、VARIANTS にセット）
js/numbers.js     ③ かずならべ（VARIANTS に数字の組み合わせ）
js/puzzle.js      ④ パズル（MOTIFS にピース定義）
assets/fonts/     Zen Maru Gothic（アプリ内の文字だけに絞ったサブセット、SIL OFL）
assets/images/    アプリアイコン
```

効果音は Web Audio で合成、読み上げは iPad 標準の音声合成を使うため、音声ファイルは不要です（`assets/audio/` は差し替え用の空フォルダ）。

## 更新するとき

ファイルを変更したら `sw.js` の `CACHE_NAME` の番号を上げてください（例：`wakuwaku-tablet-v2` → `v3`）。上げないと、ホーム画面のアプリが古いキャッシュのまま動きます。

画面に新しい文字を追加した場合は、フォントのサブセットにその文字が含まれていないことがあります（その文字だけ別の丸ゴシックで表示されます）。
