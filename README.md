# わくわくタブレット

2〜3歳向けの iPad 用知育アプリ（PWA）。GitHub Pages で公開し、Safari の「ホーム画面に追加」でオフライン動作します。

## コンテンツ

| コンテンツ | ステージ |
|---|---|
| ① なぞりがき | よこの せん / たての せん / くねくね / やま / まる |
| ② しんけいすいじゃく | どうぶつ4枚 / くだもの4枚 / かたち6枚 / のりもの6枚 / うみの いきもの6枚 |
| ③ 数字ならべ | 1と2 / 1〜3 / てんてん→すうじ / すうじ→てんてん / 1〜4 / 1〜5 / 1〜6 / 1〜7 / 1〜8 / 1〜9 / 1〜10（11ステージ） |
| ④ パズル | りんご(2) / おうち(3) / ゆきだるま(3) / くるま(4) / うさぎ(4) |

ステージは画面上部のボタンで切り替え。クリアすると大きな「〇」と紙吹雪のあとに「やったね！」が出て、「つぎへ」で次のステージに進みます。できなかったときはその場所に「×」が出ます（画面はゆらしません）。操作中の演出はありません。クリア済みは緑、遊んでいるステージは黄色で表示されます。

## 構成

```
index.html        画面の器（メニュー・確認・ほめる演出・設定）
manifest.json     PWA 設定
sw.js             オフラインキャッシュ
css/style.css     全スタイル
js/app.js         画面切替・ホーム長押し・効果音・読み上げ・ステージ管理
js/tracing.js     ① なぞりがき（VARIANTS にパスを追加すればステージが増える）
js/memory.js      ② しんけいすいじゃく（ITEMS に絵柄、VARIANTS にセット）
js/numbers.js     ③ かずならべ（VARIANTS に数字の組み合わせ）
js/puzzle.js      ④ パズル（MOTIFS にピース定義）
assets/fonts/     Zen Maru Gothic（アプリ内の文字だけに絞ったサブセット、SIL OFL）
assets/images/    アプリアイコン
```

効果音は Web Audio で合成、読み上げは iPad 標準の音声合成を使うため、音声ファイルは不要です（`assets/audio/` は差し替え用の空フォルダ）。

## 更新するとき

ファイルを変更したら `sw.js` の `CACHE_NAME` の番号を上げてください（例：`wakuwaku-tablet-v2` → `v3`）。上げないと、ホーム画面のアプリが古いキャッシュのまま動きます。

画面に新しい文字を追加した場合は、フォントのサブセットにその文字が含まれていないことがあります（その文字だけ別の丸ゴシックで表示されます）。
